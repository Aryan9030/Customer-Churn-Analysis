# Customer Churn Analysis

## Objective

Analyze customer data to identify patterns behind subscription cancellations and suggest retention strategies.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The dataset contains:

* CustomerID
* Tenure
* Monthly Charges
* Churn Status

## Key Findings

* Customers with shorter tenure are more likely to churn.
* Higher monthly charges are associated with churn.
* Customer retention improves with longer subscription periods.

## Conclusion

Customer churn can be reduced through better customer engagement, loyalty programs, and improved customer support.
